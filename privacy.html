メモ帳 プライバシーポリシー

1. 保存するデータ

メモの本文、フォルダ、挿入した画像やファイルは、利用者の端末内にのみ保存します。開発者のサーバーへ送信することはありません。

2. Googleドライブの利用

利用者がGoogleアカウントと連携した場合、バックアップのためにGoogleドライブを利用します。権限は「drive.file」のみで、このアプリが作成したバックアップファイル以外のファイルを読み取ったり変更したりすることはありません。

バックアップは利用者自身のGoogleドライブ内の「メモ帳バックアップ」フォルダに保存され、開発者を含む第三者が閲覧することはありません。

3. Googleユーザーデータの取り扱い

Google APIから取得した情報は、バックアップの作成・一覧表示・復元にのみ使用します。広告や分析への利用、第三者への提供・販売は行いません。

本アプリによるGoogle APIから受け取った情報の使用は、Google API Services User Data Policy（Limited Use要件を含む）に準拠します。

4. データの削除

アプリを削除すると端末内のデータは消去されます。ドライブ上のバックアップは、利用者がGoogleドライブから直接削除できます。連携の解除は、Googleアカウントの「サードパーティのアプリとサービス」から行えます。

5. 改定

本ポリシーを変更する場合は、このページを更新します。
