本棚のガイド

保存した漫画の画像を取り込んで読む本棚です。画像やデータは、あなたの端末(と、ペアリングした PC)の中だけに置きます。どこにも上げません。

  • 入れ方(iPhone・Android・PC)
  • PC とスマホをペアリングする
  • 同期のしくみ
  • 取り込み
  • 一覧・作品フォルダ
  • 画像の棚(イラスト)
  • 読む
  • ZIP で渡す・残す
  • PC の便利な使い方
  • 注意(データを守る)

入れ方

iPhone・iPad(Safari)

  1. Safari でこのページの本棚(本棚を開く)を開く
  2. 共有ボタン(四角から矢印が出ているマーク)→「ホーム画面に追加」→「追加」
  3. ホーム画面の「本棚」から開く。最初に「スマホ・タブレットとして使う」を選ぶ

ホーム画面から開いて使ってください。Safari のまま使うと、しばらく開かない間に iPhone がデータを消してしまうことがあります。

Android(Chrome)

  1. Chrome で本棚を開く
  2. 右上の「︙」→「ホーム画面に追加」または「アプリをインストール」
  3. ホーム画面の「本棚」から開く。最初に「スマホ・タブレットとして使う」を選ぶ

Android では、ほかのアプリ(ギャラリー・ファイルなど)の「共有」から、画像や ZIP を本棚へ送れます。

PC(Windows の Edge・Chrome)

  1. Edge で本棚を開く
  2. アドレスバーの右の「アプリを使用できます」のマーク(または「…」→「アプリ」→「このサイトをアプリとしてインストール」)でインストール
  3. 最初に「PC として使う」を選び、本棚フォルダを選ぶ(空のフォルダ。例:ドキュメントの中に「本棚」を作る)
  4. Edge が「このフォルダの編集を許可しますか?」と聞いたら「ファイルの編集を許可する」

本棚フォルダには「作品名\001.jpg」のように画像が並びます。管理データは同じフォルダの komashelf.json です。次からは開くたびに「本棚フォルダを開く」を1回押します(ブラウザの決まりです)。

PC とスマホをペアリングする(最初の1回だけ)

  1. スマホと PC を同じ Wi-Fi につなぐ
  2. PC の本棚で、右上の「︙」→「同期(スマホとつなぐ)・設定」→「ペアリングの番号を出す」
  3. スマホの本棚で「︙」→「同期(PC とつなぐ)・設定」を開き、PC に出た4桁の番号を入れて「ペアリング」

番号は10分間使えます。ペアリングした相手としかつながりません。

同期のしくみ

  • 同じ Wi-Fi で、スマホと PC の両方で本棚を開いている間、自動でつないで両方向に同期します(閉じている間は同期しません)。
  • PC が正本です。同じ作品を両方で変えていた時は、スマホに「PC版 / iPhone版、どちらを優先しますか?」と出ます。
  • 読んでいる位置は、新しく読んだ方を使います。削除したものはゴミ箱に入り、30日間は戻せます。
  • はじめに相手を見つける時だけ、無料の公開サーバー(PeerJS)を使います。画像と管理データはそこを通らず、Wi-Fi の中だけを流れます。そのサーバーが止まっている時は同期できません(ZIP で渡せます)。
  • スマホで「端末に残す」をオフにした作品は、PC に渡し終えたらスマホから画像を消して容量を空けます。読む時は PC から取り寄せます(同じ Wi-Fi で PC の本棚が開いている時)。

取り込み

  • 一覧の右下の「取り込み」から。スマホ・タブレットは押すとすぐ選ぶ画面が開きます(画像と ZIP。Android は先に「カメラ/ファイル」を聞かれるので「ファイル」を選びます)。PC は画像・フォルダ・ZIP を選ぶか、本棚の窓にドラッグ&ドロップ。
  • 並びはファイル名順です(「10 (2).jpg」のような名前の違いも吸収します)。後から作品フォルダで並べ替えられます。
  • 取り込み先:新しい読み切り / 新しい連載(第1話) / 既存の連載に新しい話 / 既存の作品の末尾。
  • 作品名の欄に「[サークル名 (作者名)] 作品名」を貼ると、自動で3つに分けて入れます。
  • 本棚で保存した ZIP(中に komashelf.json がある)は、作品名・作者・タグ・話・メモもそのまま元通りに取り込みます。
  • 取り込む画像が本棚にもうある時は「n枚中m枚は『作品名』にもうあります」と出ます。重なる分を外す・全部取り込む・やめる、から選びます(ゴミ箱の中は数えません)。

画像の棚(イラスト)

  • 1枚〜数枚のイラストは「画像の棚」に置けます。漫画の本棚とは別に、絵を切り取らずに元の形のまま敷き詰めて並べます(複数枚の作品は右上に枚数)。
  • 切り替え方:ホームのタブ(家のアイコン)を開いている時に、もう一度押します。画像の棚の時はアイコンが写真になり、もう一度押すと本棚に戻ります。作品のタブからホームを押した時は切り替わらず、最後に見ていた方に戻ります。
  • 入れ方:作品フォルダの「︙」→「移動」で「画像」を選ぶ。取り込み画面の「保存先」で「画像」を選ぶ。画像の棚を開いて「取り込み」を押すと、最初から保存先が「画像」になっています。
  • 押すとすぐ全画面で見られます。左右にめくると、そのまま前後の作品へ続きます。長押し(PC は右クリック)で作品フォルダ。
  • 検索・タグ・並び替え・スクロール位置は、本棚と画像の棚で別々に覚えます。並び替えが「作者毎」の時は、本棚と同じく作者ごとの束にまとめます(画像の棚の作品だけ)。本棚の「作者毎」には画像の棚の作品は入りません。

読む

  • 縦長の画面は1ページずつ、右開き(左へめくる)。左右の端を押してもめくれます。真ん中を押すとバー。
  • 横長の画面は、ページを右から左へ横一列に並べて流します。見開きの組み方(1|2-3 / 1-2|3-4)は左上のボタンで切り替え。
  • 2本指で拡大(PC は Ctrl+ホイール)。連載は最後のページから次の話へそのまま続きます。

ZIP で渡す・残す

作品フォルダの「︙」→「ZIPファイルで保存」、または一覧の「︙」→「選択する」で複数選んで ZIP に。ZIP は Android・iPad 版の本棚とも互換で、どの端末の「取り込み」でも元通りに戻ります。

PC の便利な使い方

ほかのタブの画像を本棚へドラッグ / 画像をコピーして Ctrl+V取り込み画面に並ぶ(作品フォルダを開いていれば、その作品に足す形で)
本棚フォルダの「取り込み待ち」画像や ZIP を入れておくと、取り込み画面を開いた時に並ぶ(取り込んだら消えます)
← → Space PageUp PageDown ・ホイールページをめくる
Ctrl+ホイール読む画面は拡大、一覧・作品フォルダは表紙の大きさ
F / Esc全画面 / 戻る
右クリック・Ctrl/Shift+クリック・Deleteメニュー・複数選択・ゴミ箱へ
横に流せる列の上でホイール横に流す(端で止まります)

注意(データを守る)

スマホのホーム画面の「本棚」のアイコンを消すと、中のデータも消えます。PC とペアリングして同期しておくか、ZIP で残しておいてください。

  • 同じ端末で本棚を2つのタブで開くと、後から開いた方は止まります(データが食い違わないように)。
  • Web版を直した時は「新しい版があります。開き直す」が出ます。押すと新しい版で開き直します。
  • PC の本棚フォルダの中のファイルは、なるべく本棚の画面から変えてください(エクスプローラーで消した画像は「画像が見つかりません」になります)。
